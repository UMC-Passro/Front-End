# 패스로(Passro)

## 1. 프로젝트 소개

패스로는 대학생이 매일 오가는 통학 경로를 활용해 소형 택배를 대신 배송하는 P2P 배송 플랫폼입니다.

사용자가 배송 요청 등록, 운송 가능 경로 확인, 매칭, 배송 진행 상태 확인 등의 핵심 기능을 편리하게 이용할 수 있도록 모바일 환경에 최적화된 웹 화면을 개발합니다.

│   └── verification       # 학생 인증 모달
├── hooks
│   └── useApiRequest.ts   # API 로딩·오류·데이터 상태 관리

## 5. 브랜치 전략

```text
main
└── dev
    └── feature/기능명
```

- `main`: 최종 배포용 브랜치
- `dev`: 개발 통합 브랜치
- `feature`: 기능 단위 작업 브랜치

## 6. 커밋 컨벤션

```text
feat: 새로운 기능 추가
fix: 버그 수정
docs: 문서 수정
style: 코드 포맷팅
refactor: 코드 리팩토링
chore: 기타 설정 변경
```

예시:

```text
feat: 로그인 페이지 UI 구현
fix: 라우팅 오류 수정
docs: README 실행 방법 추가
```

## 7. PR 컨벤션

### PR 제목 양식

```text
[type] 작업 내용 요약
```

`type`은 커밋 컨벤션의 `feat`, `fix`, `docs`, `style`, `refactor`, `chore` 중 하나를 사용합니다.

예시:

```text
[feat] 배송 요청 등록 페이지 UI 구현
[fix] 배송 상태 라우팅 오류 수정
[docs] README 화면 플로우 추가
```

### PR 본문 양식

```md
## 수정자
- 이름 또는 GitHub ID

## 작업 내용
- 구현한 기능 설명

## 변경 사항
- 수정된 주요 파일 또는 구조

## 확인 사항
- 실행 여부
- 에러 여부
- 추가 확인이 필요한 부분
```

### 현재 프론트 화면 흐름

```text
로그인 또는 회원가입
└── 역할 선택
    ├── 발송자
    │   └── 발송자 홈
    │       ├── 배송 요청 약관 동의
    │       │   └── 배송 요청 정보 입력
    │       │       └── 예상 정산 금액 확인
    │       ├── 진행 중 배송 상태 확인
    │       └── 최근 배송 내역 확인
    └── 배송자
        └── 학생 이메일 인증
            └── 배송자 홈
                ├── 매칭 요청 상세 확인
                │   └── 매칭 수락
                └── 물품 인수
                    └── 배송 중
                        └── 전달 완료 요청

홈 프로필 이미지
└── 마이페이지
    ├── 프로필 수정
    ├── 포인트 내역
    ├── 배송 내역
    └── 로그아웃
```

### 목표 MVP 흐름

1. 발송자는 출발지, 도착지, 물품 크기, 사진을 포함해 배송 요청을 등록합니다.
2. 시스템은 배송 요청과 배송자의 통학 경로를 비교해 유사도가 높은 배송자를 탐색합니다.
3. 발송자는 추천된 배송자 후보를 확인하고 매칭 요청을 보냅니다.
4. 배송자가 요청을 수락하면 매칭이 확정되고 발송자에게 알림이 전달됩니다.
5. 배송자는 픽업, 이동 중, 배송 완료 등 배송 상태를 단계별로 업데이트합니다.
6. 배송 완료가 확인되면 포인트가 자동 정산됩니다.
7. 배송 완료 후 발송자는 리뷰와 평점을 남길 수 있습니다.
